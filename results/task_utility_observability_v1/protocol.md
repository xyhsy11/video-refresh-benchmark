# Experiment 22: Task-Utility Observability and Cost Feasibility

EXPLORATORY / DEVELOPMENT, version 1. Main base e65e3a1c4066e2360cec1a45dd558060f0532359. This protocol is specified after exposure to Experiment 21's development findings, before constructing the new task-utility targets or fitting diagnostic probes. It supplies no independent confirmation or publication-readiness claim. Preserve all historical evidence; never open UCF official-test outputs/features/reports or HMDB test inputs. No network, decoding, Torch/CUDA import, video inference, new recognition head or adaptive controller training. CPU affine replay and small linear probes are allowed. Existing genuine embeddings, encountered thumbnails/statistics and actual timing are the only empirical inputs.

## Population and observation distribution

Inherit ALL Experiment 21's 404 controller-training clips/202 groups, 202 selection clips/101 groups, and 400 execution clips/200 groups, with all 101 classes and only official split-1 TRAINING membership. Independently verify actual counts, official trainlist01 membership, byte hashes, group/known duplicate isolation and original input/grid/encoder lineage. No substitution, class search or role changes. Group means (class,gXX) are operational independent units; unknown parent-source/reupload/pretraining relationships remain limitations.

PRIMARY distribution: only the deterministic periodic B4 [0,4,8,12] chronological prefixes, on all roles. Reproduce saved periodic controller-training inputs; authenticate executed periodic prefixes/selected features on execution clips. Do not mix policies or weight states as independent videos. SECONDARY populations: the saved seeded-random execution prefixes, and separately the ACTUAL executed H+M prefixes. Probes are fitted/selected ONLY on periodic training/selection states and transported unchanged to both secondary populations. Secondary differences expose state-distribution dependence; they are not additional independent cohorts.

Retain every t=1..15 state, including exhausted/forced decisions, with original clip/class/group/role, candidate actual PTS/frame index, age, remaining budget, exact refresh prefix and generating policy. Mandatory t=0 precedes a cached observation and is not a probe state. Fit/evaluate predictability only on discretionary states with both refresh/hold feasible: 0 < remaining < 16-t. No gain-based exclusions. Positive event is strictly gain > 0, exact zero is nonpositive; preserve near-zero abs(gain)<=1e-10 as a descriptive numerical category without excluding/relabeling it. The old study used a 1e-12 descriptive helpful threshold; do not silently conflate that with this new target definition.

Use identical states for constant, time/age/budget/discretionary baseline, H, M and H+M. No full feature matrix enters the observation API.

## Fixed diagnostic probes and selection

No new refresh controller. Fit weighted logistic linear classification and weighted ridge signed-gain regression independently for A and B and each view. Grid [0.001,0.01,0.1,1.0]; constant predictor has only an intercept. Train-only means/SD, constants scaled by 1. Objective is normalized empirical BCE or half MSE plus alpha/2 ||w||^2, unpenalized intercept. Equal classes, then equal groups/class, clips/group, states/clip; no event rebalancing. Logistic uses deterministic float64 SciPy L-BFGS-B, max400 iterations, max40 line-search steps, history20, ftol1e-12, gtol1e-8. Ridge solves its weighted normal equations. Same inputs/populations/optimization grid for H versus H+M. Record convergence and every grid value. No architecture search or target revision.

Classifier alpha: minimum raw selection Brier, then maximum selection average precision, then grid order. Regression alpha: minimum selection MAE, then maximum weighted Spearman, then grid order. Fit a nondecreasing selection-only Platt map afterward (slope >=0, fixed .01 quadratic penalty toward slope1, unpenalized intercept); report both raw and calibrated metrics. Thresholds [.25,.5,.75] maximize calibrated selection F1, then precision, then grid order. Never select against descriptive execution. Save models/hashes before execution-cohort predictions; original head/controller policies remain untouched.

## Metrics, weighting and uncertainty

Report positive prevalence, weighted noninterpolated PR AUC (average precision), tie-aware ROC AUC, Brier, 10 equal-width calibration bins, selection-threshold precision/recall; signed-gain MAE, weighted Spearman (weighted mid-CDF ranks), signed bias, sign errors and weighted error quantiles. AUC undefined if either class absent; constant-score ROC is .5 and AP is prevalence. Class/group/clip/state hierarchy defines the same weighted distribution for every metric. No individual decision is an independent video.

Prespecified primary comparisons: H-baseline, H+M-H, M-baseline and M-constant. Use 2,000 PCG64 seed20261022 class-stratified paired GROUP bootstrap draws; save indices, reuse identical groups/draws for every target/method/population. Carry all clips/states together; recompute nonlinear metrics with repeated-group weights. Marginal percentile intervals on calibrated classification and signed regression metrics; no multiplicity correction, equivalence margin or power guarantee. Training/selection uncertainty and prior head/controller exposure are omitted. One execution group in BenchPress and JavelinThrow cannot estimate within-class group variance. Selection has only one group/class. Secondary strata: candidate1-4,5-8,9-15 and remaining budget1/2/3; descriptive conditional hierarchy with coverage counts, no separate confirmatory intervals. Flag fewer than20 represented groups as sparse. Summarize actual gain/age/budget/position/teacher/MAD distributions.

Compare conditional proxy-teacher actions with BOTH target signs, including weighted confusion and wrong-branch hindsight regret. Task-oracle and Z_pool schedules are privileged diagnostics. Exact full455 task-oracle headroom versus periodic distinguishes limited useful scheduling opportunity from objective mismatch. Retrospective local/branch gains are not the downstream causal effect of changing the executed controller.

Independently reproduce existing timing from trial rows: per-video median of five measured repetitions, two warmups excluded. Report paired increments H-periodic, H+M-periodic, H+M-H, periodic+unusedgate-periodic. Bootstrap timing MEDIANS over the30 groups with PCG64 seed20261023 (2,000 draws); never repetitions. Thumbnail/statistics are nested within observation-preparation; do not double count. No replay-derived latency or hypothetical fused-decoder speedup. Report descriptive recognition/latency dominance both for the matched30 timing clips and separately the400-quality/30-cost combination; acknowledge different populations and noise. Predictive probe gains do not establish policy utility or justify a cost by themselves.

Assess H1 teacher mismatch, H2 limited causal information, H3 objective/learner extraction limits, H4 overhead, H5 limited hindsight headroom. Distinguish direct observations, supported associations, consistency and unresolved explanations. Choose SIGNAL_INFORMATION_SUPPORTED, SIGNAL_INFORMATION_NOT_ESTABLISHED or INCONCLUSIVE_DATA_OR_RESOURCE_LIMITATION using effect sizes, uncertainty, source coverage, bias, simple-model limitations and actual costs, never CI significance alone. Stop; no fresh inference or architecture search.
