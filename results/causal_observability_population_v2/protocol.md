## Inputs and temporal amendment

Reuse the retained original unstabilized HMDB51 AVI archive and official split-1 annotations at the previously authenticated Serrelab revision. No acquisition, replacement, new terms, or package installation is implemented. Verify archive hashes, original inner-archive bytes, and every AVI against a fresh read of authenticated archive members. Parse original split-1 membership; flag 0 is never training. All annotated clips are screened, including historical failures. Missing genuine bytes, decoder or solver resources produce INCONCLUSIVE_RESOURCE_BLOCKED, not mathematical infeasibility.

Software decoding uses the existing PyAV configuration: one thread, NONE thread type, skip_frame NONE. Decode complete original clips. Require every frame to have finite, valid, distinct actual PTS; apply the existing stable presentation_order utility and retain original decode ordinals and integer PTS/time bases. Do not discard bad timestamps to rescue a clip. Require N >= 19 frames. Define exactly 16 endpoint indices floor(linspace(3,N-1,16)). For endpoint i, left_time=searchsorted(PTS,PTS[i]-47/30,side='left'), left=min(left_time,i-3), and four snippet indices floor(linspace(left,i,4)). Require strictly increasing distinct indices, last index i, with no future frame. Record actual indices, original ordinals, integer PTS, time bases, times, offsets, window spans, extension flags and candidate times. Rule identity: adaptive_history_index_uniform_v2. Clip duration is the decoded PTS span; container duration is separately labeled if available.

This is a scientific protocol change, not equivalence to the old [47/30,32/30,16/30,0] offsets. Index-uniform endpoints can be temporally nonuniform for VFR. Four consecutive frames may contain little motion. The nominal window may be extended only to obtain four genuine frames. No looping, repeats, padding, interpolation, trimming, outcome-based replacement or historical eligibility filter is used. Recompute historical eligibility separately with the unchanged historical snippet_grid, and reconcile with the saved v1 journal.

## Conservative source components

Construct global clip connected components using (a) exact byte equality, (b) the unchanged historical conservative three-frame pHash criterion: 63-bit DCT hashes at floor(.1/.5/.9*(N-1)), all Hamming distances <=4, decoded PTS-span ratio >=.9, and (c) shared normalized source titles from the existing source_family function. Fingerprints are input-only and are computed also for newly recovered clips; all pairwise qualifying pHash edges are retained, including edges within existing components. Thresholds are inherited, not tuned on this test set. Fixed thumbnail conversion uses gray, Pillow resize to 32x32 (BICUBIC), DCT-II orthonormal, first 8x8 excluding DC, strict greater-than median. No manual retain overrides.

Source-title equality is a conservative relationship proxy, not proof of a common original source. Different titles do not prove independence. Missing original URLs, parent identifiers and pretraining/reupload mappings remain unknown. Components containing title links or only singleton metadata have uncertain external independence. Component isolation is an operational protection against observed links, not a guarantee of universal independence. Audit components >=20 clips, top 15 components, cross-class links, and all official train/test conflicts. Never split a component to regain samples. The primary rule gives priority to ALL official test families, including technically failed test members, matching v1 conservatism: retain every eligible official test clip and exclude related official training clips. Unused clips can transmit known relationships but cannot fill roles. Report exact-only and exact+pHash grouping as explicitly less conservative sensitivity counts; they cannot justify GO. Also show the effect of title grouping and the union. Known confirmed links are never removed from the primary.

## Prespecified global allocation grid

Keep all 51 classes. A requires per-class minima (head_train,controller_train,development,test)=(30,10,10,10); B=(25,10,5,10); C=(20,8,5,10). Every training role additionally needs >=3 distinct operational conservative source components/class; test needs >=5/class. These are engineering minima, not power or training-sufficiency guarantees.

After test-priority quarantine, assign each remaining eligible official-training component wholly to one of the three training roles. No training-family splitting and no reassignment of test/unused clips. All surplus training families are assigned, not silently discarded. For each A/B/C, solve one global binary MILP with three variables/family, exactly one role/family, clip-count and family-count lower bounds per class/role. Cross-class component relationships enter the same variables. Objective: minimize deterministic SHA256-derived role costs in [0,1), seed 20261019, family order sorted by a separate seeded hash. SciPy milp/HiGHS, threads=1, random_seed=20261019, time_limit=300 seconds, mip_rel_gap=0, mip/primal feasibility tolerances 1e-7. Record actual versions, objective, bounds/gap, termination and warnings. No timeout is called infeasible. Independently derive necessary count/group certificates; these alone can prove a configuration impossible, including fixed test constraints. Independently validate every obtained integral assignment. Repeat each solver call and require identical status and assignment. Strongest fully verified feasible configuration A>B>C wins; unresolved stronger searches block finalization until resolved. A proven necessary-condition failure is not a solver-resource failure.
