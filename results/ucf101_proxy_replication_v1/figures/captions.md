The recognition figures use X3D-XS, T=16, B=4 and C pooling on all 704 eligible test groups / 1,408 clips / 101 classes. C weights candidate reuse counts divided by 16, rather than elapsed time. Means average clips within group, groups within class, then classes equally. Intervals use 10,000 PCG64 seed-20261026 class-stratified paired group bootstrap replicates.

- `primary_intervals`: g=CE(Z_pool)-CE(LegacyCosine) is primary; p=CE(Z_pool)-CE(periodic) and d=CE(LegacyCosine)-CE(periodic) are secondary, marginal/unadjusted. Negative favors the first selector. Width of the primary interval is 0.013039735 nats.
- `fidelity_recognition`: descriptive selector means show dense-to-selected KL versus recognition CE. Points have no displayed uncertainty bands and do not establish a universal or causal fidelity/task relationship. All proxy selectors require 16 dense encodings plus CPU search.
- `decomposition`: g equals the directional difference plus the KL difference. The total uses the primary paired interval; component intervals are secondary, marginal/unadjusted. Component endpoints must not be added to construct a total interval. The wider layout replaces overlapping ticks; the original render is retained under `pre_visual_review`.
- `measured_cost`: each line is one fixed test group, from 30 distinct classes, using one frozen clip/group. Points are within-clip medians of five measured repetitions per mode after two warmups. The boundary is encoded bytes in memory through fresh full decode/PTS planning/preparation/transfer/native encoder and pooled new head to CUDA-completed prediction. Repeats are not additional independent groups. These timings apply to dense16 and periodic B4, not privileged proxy/oracle quality.
- `population_design`: input-only eligibility and duplicate-quarantine counts, before test outcomes. Its original visual-review record is separate from the four required outcome/cost figures.
