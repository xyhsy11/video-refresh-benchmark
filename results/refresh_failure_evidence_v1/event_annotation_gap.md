# Event annotation and observability gap

The retained evidence contains genuine endpoint timestamps/frame identities, cheap 32x32 grayscale statistics and signed task targets. MAD compares adjacent candidate thumbnails, whereas local gain compares the last actual cache with the current dense feature. Different reference intervals matter: large pixel change need not be task-relevant, and a quiet frame may contain discriminative evidence. Six numeric change summaries are analyzed without promoting the pre-existing threshold flag to a semantic event annotation.

No authenticated per-event camera-cut, camera-motion, object-entry/exit, occlusion, action-onset/offset, semantic novelty or discriminative-moment annotations were supplied. Class labels and filename source groups are not event labels. This audit therefore cannot estimate event-conditioned gain, distinguish camera movement from action movement, or count event-detection misses. Missing annotation is not evidence of absence. No new annotation is invented from a gain sign, proxy magnitude, oracle schedule or chosen failure case.

A later annotation study would need authorized source video, a frozen label ontology, genuine PTS/frame intervals and uncertainty flags, annotators blind to all model predictions/gains/policies, documented agreement, complete prespecified sampling, and source-family-disjoint role assignment before evaluation exposure. Retrospective annotations must remain explanatory labels; a deployable event sensor would separately require pre-decision availability and measured acquisition latency. Annotation existence alone does not make an event observable by a cheap runtime gate.

The missing useful signal is therefore specific in function, but not yet identified in modality: a pre-decision observation of task-relevant change relative to the current cache that predicts the signed **final exact-B4 budget gain conditional on history/time/budget**, with replicated incremental performance on untouched families. Current MAD/RMS/histogram change, confidence transforms, label-informed hindsight and future embeddings do not satisfy that requirement. There is no evidence here that an unmeasured cut detector, motion feature or event model would satisfy it.
